# Transitions Lab: reference library

Every named author, named theory and named term of art used in the article series, with the canonical source it should link to at first mention in body prose.

**The rule this file exists to serve.** A concept named in prose is a link, not a sources-list entry. "Kydland and Prescott's account of time inconsistency", "the collective-action problem", "the rebound effect", "the bundle of rights" all carry a hyperlink at first mention. Leaving them unlinked in the draft pushes the work to a post-publication audit pass, which is what has been happening.

**Verification status is stated for each.** Confirmed means the DOI or URL was checked in a search result. Site-resolved means it was found and linked during a build audit and should be treated as the site's chosen citation. Needs link means no verified target yet, and any article using it must flag that in its build block.

## Working practice

**Before using a term of art, check this table.** If it is here with a confirmed or site-resolved target, link it. If it is not here, either verify the canonical source and add a row, or use plain language instead. A concept named without a citation reads as jargon; a concept named with one reads as scholarship.

**Nine entries currently need a link.** These are the ones to resolve when there is a spare search: Hirschman 1958, Sen 1999, David 1985 QWERTY, Gerarden Newell and Stavins 2017, the EEI death spiral paper, the firefighting trap origin, and better targets for Jaffe and Stavins 1994, Feder Just and Zilberman 1985, and David 1990.

**Add a row every time a new framework is used.** The series runs one new framework per piece, so this file grows by three or four rows a day. Keeping it current is what stops the audit passes.

**Books.** Where no DOI exists, link the publisher page rather than a bookseller, and never construct a URL from a title.
